# Что это за звук? Классификация окружающих звуков

Учебный проект на PyTorch: CNN классифицирует пятисекундные записи по log-mel спектрограммам. Первая версия работает с ESC-10, подмножеством датасета ESC-50. Готовые веса модели в репозиторий не включены.

## Данные и постановка

В [ESC-50](https://github.com/karolpiczak/ESC-50) есть 2 000 записей и 50 классов; ESC-10 содержит 400 записей 10 классов. Для каждого аудиоклипа модель выдаёт один класс. Исследуем, как добавление шума при обучении влияет на качество классификации зашумлённых звуков.

Используются официальные разбиения: folds 1–3 для обучения, 4 для выбора лучшей эпохи по macro-F1, 5 для финальной проверки. Для более надёжного сравнения нужно повторить эксперимент на всех пяти тестовых fold с отдельным validation fold и несколькими seed. После изучения тестового результата нельзя подбирать по нему настройки, иначе оценка будет смещена.

ESC-50 распространяется по лицензии CC BY-NC 3.0, а ESC-10 — CC BY; учитывайте условия и атрибуцию отдельных записей. Авторы отмечают потенциальные признаки утечки из-за обработки некоторых исходных аудиофайлов; подробности см. в описании датасета.

## Установка

Требуется Python 3.10–3.12. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Linux/macOS: `source .venv/bin/activate`, затем `python -m pip install -r requirements.txt`. Для GPU может понадобиться подходящая сборка PyTorch с [официальной страницы](https://pytorch.org/get-started/locally/).

Скачайте [архив ESC-50](https://github.com/karolpiczak/ESC-50/archive/refs/heads/master.zip), распакуйте его и поместите содержимое в `data/ESC-50/`. Должны существовать `data/ESC-50/meta/esc50.csv` и `data/ESC-50/audio/`. Сам датасет не включён в этот проект.

## Обучение и запуск

Из корня проекта:

```bash
python -m src.train --epochs 20
streamlit run app.py
```

Лучшая по validation macro-F1 модель сохраняется в `checkpoints/best.pt`. После обучения скрипт один раз оценивает выбранную модель на fold 5 и записывает accuracy, macro-F1, отчёт по классам и матрицу ошибок в `results/test.json`. Для быстрого пробного запуска можно указать `--epochs 1`.

Интерфейс принимает WAV, преобразует его в моно и 22 050 Гц, обрезает до 5 секунд или дополняет тишиной. Он всегда выбирает из 10 известных классов, даже если загруженный звук к ним не относится. Вероятности модели не гарантированно откалиброваны.

## Эксперимент с шумом

Пример двух запусков с одинаковым seed и отдельными выходными файлами:

```bash
python -m src.train --seed 42 --noise 0 --test-noise 0.01 --output checkpoints/clean.pt --results results/clean-noisy-test.json
python -m src.train --seed 42 --noise 0.01 --test-noise 0.01 --output checkpoints/augmented.pt --results results/augmented-noisy-test.json
```

`--noise` добавляет гауссов шум только к обучающим данным; `--test-noise` — к тестовым. Сравните также качество на чистых данных и повторите с разными seed и fold. Для воспроизводимости тестовый шум генерируется с заданным seed при последовательном чтении данных. Эти команды заново обучают модели. Для интерфейса нужен файл `checkpoints/best.pt`.

## Результаты первого эксперимента

Сравнили две модели: первую обучили на чистых записях, вторую — с добавлением гауссова шума ко всем обучающим записям (`noise=0.01`). Каждую модель проверили на чистых записях и на тех же записях с добавленным шумом (`test_noise=0.01`). В обоих запусках использовался `seed=42`; лучшая эпоха выбиралась по macro-F1 на чистой validation-выборке.

| Модель | Чистый тест: accuracy / macro-F1 | Тест с шумом: accuracy / macro-F1 |
|---|---:|---:|
| Обучение на чистых записях | 83,75% / 0,837 | 47,50% / 0,373 |
| Обучение с добавлением шума | 46,25% / 0,412 | 67,50% / 0,673 |

В этом эксперименте модель, обученная с шумом, лучше распознавала зашумлённые записи, но хуже работала на чистых. Это предварительный результат: проверка проведена на одном разбиении и одном seed, в тесте всего 80 записей — по 8 на класс. Тест уже использовался для нескольких сравнений, поэтому для окончательной оценки следующей версии нужна независимая отложенная выборка. Более надёжное исследование также требует нескольких seed и разных разбиений.

## Ограничения и развитие

Здесь реализована только своя CNN; сравнение с предобученной аудиомоделью и полная пятифолдовая оценка остаются следующими этапами. Короткая запись дополняется тишиной, длинная обрезается: для реального приложения потребуется более продуманная обработка длинного аудио и неизвестных классов.
